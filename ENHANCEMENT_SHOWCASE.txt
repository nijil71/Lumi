1. PROGRESS BAR
   ├─ 3 new styles: modern, fluid, arrow
   ├─ Visual indicators: ETA (⏱), rate (↯), label marker (▸)
   ├─ Better percentage display with visual pulses
   └─ Example: ▸ Build [▰▰▰▱▱] 60% 30/50 ⏱ 1m40s ↯ 9.2/s

2. SPINNER
   ├─ Context markers with arrow (▸)
   ├─ Multi-line frame indicators (│)
   ├─ Modern outcome symbol (◆)
   ├─ Chainable outcome methods
   └─ Example: ▸ Build  ◆ Task complete  856ms

3. LOGGER
   ├─ Enhanced semantic icons for each level
   ├─ Step sequences with visual progress bars
   ├─ Visual bracket markers (│) in KV pairs
   └─ Example: ▸ ▪▪▪░░░░ 3/8  Building artifacts

4. TABLE
   ├─ Row and cell highlighting support
   ├─ Visual row indicators (◆) for important items
   ├─ Compact mode for dense layouts
   └─ Example: ◆ highlighted row with emphasis

5. STATUS BAR
   ├─ Leading visual marker (▸)
   ├─ Enhanced segment separation
   ├─ Style options (default, minimal, compact)
   └─ Example: ▸ ⚡ Building │ CPU 42% │ Memory 78%

6. BOX
   ├─ Glow option for emphasis (✦)
   ├─ Title decorations (◆)
   ├─ Compact mode option
   └─ Example: ┌─ ◆ Title ─────────────────┐

EXAMPLE: ENHANCED PROGRESS BAR
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

import { ProgressBar } from '@nijil71/lumi-cli';

const bar = new ProgressBar({
  total: 100,
  style: 'modern',
  color: 'azure',
  label: 'Deploy',
  eta: true,
  rate: true
});

bar.start();
for (let i = 0; i < 100; i++) {
  bar.increment();
}
bar.complete('Deployment successful');

Output:
  ▸ Deploy [▰▰▰▰▰▰▰▰▰░░░░░░░░░░░░░░░] 45% 45/100 ⏱ 2m15s ↯ 4.8/s

DESIGN PHILOSOPHY
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Lumi's visual enhancements follow core principles:

1. Functional Minimalism
   Every element serves a clear purpose. No decoration without meaning.

2. Visual Hierarchy
   Important information stands out. Secondary information recedes.

3. Semantic Consistency
   Colors and symbols convey meaning consistently across all components.

4. Professional Polish
   Polished appearance suitable for production and enterprise use.

5. Accessibility
   Never relying on color alone. All indicators include symbols or text.

6. Performance
   Zero performance impact. Efficient rendering and minimal overhead.

7. Compatibility
   Works across terminal types. Degrades gracefully on limited color support.
